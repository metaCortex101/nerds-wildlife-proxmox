Each worker has 2 vCPUs, 3 GiB RAM, and a 32 GiB disk: independent full KVM clones of the owner's Debian 13 base VM 106.

Use and verify

  1. Open the wildlife logger and enter an animal, stream, and observation time.
  2. Save, refresh, and check the shared log. Print log prints a clean table.
  3. Refresh worker identity to see requests reach different workers.
  4. Check database-aware health and the verification report.

For HTTPS trust, download the public lab CA certificate and import it into your trusted root store. Use curl --cacert nerds-lab-ca.crt for command-line checks.
